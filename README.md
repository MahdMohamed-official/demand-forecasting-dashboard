# Demand Forecasting & Retail EDA Dashboard

A Flask-based interactive dashboard for analyzing retail demand, sales, inventory, pricing, promotions, and stock-out risk.

## 📊 Overview

This project processes and analyzes **76,000 retail records** covering **5 stores, 20 products, 5 categories, and 760 days**, and presents the results through an interactive web dashboard.

## ✨ Features

* Sales and revenue analysis
* Demand and seasonal trend analysis
* Inventory and stock-out risk analysis
* Pricing, discount and promotion analysis
* Product, category and store performance
* Correlation and outlier analysis
* Data-quality and preprocessing analysis

## 🛠️ Tech Stack

**Frontend:** HTML5, CSS3, JavaScript, Chart.js
**Backend:** Python, Flask
**Data Analysis:** Pandas, NumPy, EDA, data preprocessing & feature engineering
**Tools:** VS Code, Git, GitHub

## 🚀 Run Locally

```bash
git clone https://github.com/MahdMohamed-official/demand-forecasting-dashboard.git
cd demand-forecasting-dashboard
pip install -r Requirements.txt
python App.py
```

Open `http://127.0.0.1:5000` in your browser.
